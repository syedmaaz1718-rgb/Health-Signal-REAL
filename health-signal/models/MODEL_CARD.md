# Health Signal model card

## Intended use

Educational, transparent classifiers on historical Pima and Cleveland health datasets. Educational portfolio/research demonstration. Not an automated high-stakes decision tool.

## Data

Pima: 768 records, using 2-hour OGTT glucose, diastolic BP, BMI and age. Cleveland: 303 records, using age, dataset sex coding, resting systolic BP and cholesterol.

## Model

Reduced-feature logistic regression with median imputation and standardization fitted only on training data. All weights are exported to JSON.

## Evaluation

Stratified 75/25 holdout, seed 42. Diabetes: AUROC 0.809, accuracy 72.4%, Brier 0.174 (192 test rows). Heart: AUROC 0.672, accuracy 61.8%, Brier 0.229 (76 test rows).

Metrics are generated by `training/train.py` and stored alongside weights. Split and preprocessing are recorded in the artifact. Numerical Python-to-JavaScript parity is tested, but parity is not a validation of the model's real-world suitability.

## Limitations

Improve dataset documentation, external validation, calibration and subgroup evaluation. Clinical use would need qualified medical oversight and regulatory review; this app is not a medical device.

## Explanations

Job and health bars are signed additive **log-odds contributions**, not causal effects, SHAP values or medical advice. Resume skill coverage is dictionary presence, not expertise. Traffic index bands are arbitrary project conventions.

## Deployment

JSON weights consumed locally in the browser. No retraining at deployment. No input persistence.

Pima inputs use **2-hour oral-glucose-tolerance-test glucose**, not interchangeable fasting glucose. The cohort contains adult women of Pima Indian heritage. Cleveland uses a binary historical sex encoding that does not represent all identities. Heart-model test discrimination is weak (AUROC 0.672). Selected inputs are insufficient to establish medical safety or diagnosis.
